# Contributing to Application Tracker

Thank you for contributing to Application Tracker.

This document defines the development workflow, branch naming rules, commit conventions, testing requirements, and pull-request expectations for the project.

## Development Requirements

Before contributing, install:

- Node.js
- npm
- Git

Additional services may be required for database and authentication features:

- Neon PostgreSQL
- Clerk
- Prisma ORM

## Local Setup

Clone the repository:

git clone https://github.com/MelvinBerkoh/application-tracker.git
cd application-tracker
